Sobre mí

Soy Gustavo Garcia un estudiante de la carrera de Desarrollo de Software, al cual le gusta la tecnología y el diseño web. Esta página fue creada como ejercicio práctico para aplicar los fundamentos del lenguaje HTML.

Todo el html esta estructurado de forma correcta con el uso de las etiquetas que emos visto en clases, como <nav>, <main>, <section>, <header> y <footer>.

Mi objetivo es seguir emplear lo aprendido de html para construir web completas y accesibles.
